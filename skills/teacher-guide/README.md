# 让 AI 照《中国教师生活指南》回答

装上之后，可以直接问「被家长投诉了怎么办」「小学老师评高级有多难」「非升即走合同要注意什么」「在二本院校怎么做科研」这类问题。它会**先把相关条目从 `book/` 里查出来**，再照书里的方式回答，并注明出自第几节第几条和证据等级。查不到就说查不到，不自己编数字。

## 装到 Claude Code

```bash
# 项目级
mkdir -p .claude/skills && cp -r skills/teacher-guide .claude/skills/

# 或用户级（所有项目都能用）
mkdir -p ~/.claude/skills && cp -r skills/teacher-guide ~/.claude/skills/
```

## 装到 Codex

```bash
mkdir -p ~/.codex/skills && cp -r skills/teacher-guide ~/.codex/skills/
```

具体目录以你所用工具的文档为准——形态都一样：一个含 `SKILL.md` 的目录。

## 它为什么不会乱答

`SKILL.md` 里定死了几条规矩，其中最要紧的是这两条：

**一、涉及心理危机时，停止讲解，直接给求助信息。**
如果对方提到「不想活了」这类念头，它会立刻给出 **12356**（心理支持）和 **120 / 110**（立即危险），不附加长篇建议，也不拿统计数据去回应处在危机中的人。这不是可选项，是安全传播的基本要求。

**二、必须带上证据等级，并且不许把 D 级讲成结论。**
指南本身 84 条里，A 级 44 条、B 级 21 条、C 级 4 条、D 级 15 条。每条 D 级都在备注里写明了「哪一半有出处、哪一半是作者的判断」。AI 沿用同一套标准，就不会把策略建议讲成验证过的方法。

它还内置了几条针对常见误用的检查，比如：

- 「教师抑郁检出率 17.5%」是检出率、不是确诊率
- 「甲状腺结节 38.86%」是一家医院的体检人群统计，不是全国流行率
- 正高级的「千分之五」和「3%/2%/1%」分母不同，不能混用
- 凡标注「草案」的尚未生效，必须说「拟规定」
