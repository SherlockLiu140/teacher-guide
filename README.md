# 中国教师生活指南

写给从小学到大学的教师。每一条都回答两个问题：**这事有多普遍，我能做什么。**

**12 节 84 条。A 级 44 条、B 级 21 条、C 级 4 条、D 级 15 条。引用 38 个可查的来源。**

每条的字段一栏都不省：成本、说人话、收益、证据等级、来源、备注。

> **在线版**：https://sherlockliu140.github.io/teacher-guide/
> **动手改之前建议先读 [免责](#免责)**——这是一份信息整理，不是法律意见或医疗建议。

## 怎么读

- **学段筛选**：选「中小学」或「高校」时，「全学段」的章节会一并显示（它们对哪个学段都适用）。章节标题上带学段徽章。

## 证据等级怎么定

| 等级 | 含义 | 条数 |
|---|---|---|
| **A** | 有具体数字，来自随机试验、荟萃分析或官方文件（**含法规条文原文**） | 44 |
| **B** | 有具体数字，但来自单项观察性研究或官方统计（含媒体报道与访谈） | 21 |
| **C** | 有明文规定或公开数据，但没有量化效果 | 4 |
| **D** | **没有直接证据**，来自明文规定或公开共识，**必须在备注里写明哪一半有出处、哪一半是判断** | 15 |

**为什么 D 级占了 18%。** 「被家长投诉了怎么办」「平台不足该怎么选方向」「怎么和室友……」这类问题不会有随机对照试验。硬标成 A 级才是害人。本书的选择是：**把有出处的部分和作者的判断分开标注，让读者自己决定信哪一半。**

几条贯穿全书的误用提醒（本书反复强调，因为网上大量文章在这里出错）：

- 「教师心理问题检出率 17.5%」是**检出率，不是确诊率**，也不能拿来推算个人概率。
- 「甲状腺结节 38.86%、慢性咽炎 61.64%」是**某一家医院体检人群的统计**，不是全国流行率。
- 正高级的「**全省岗位总量千分之五以内**」和「**高级岗位内部占 3%/2%/1%**」**分母不同**，不能混用。
- 高校淘汰率、启动经费这类数字来自**媒体报道与受访者叙述**，不能当成本校的真实数字引用。
- 凡标注「**草案**」的（如《教师法（修订草案）（征求意见稿）》）**尚未生效**，只能说「拟规定」。
- **慢性咽炎、下肢静脉曲张、颈椎病都不是法定职业病**（不在《职业病分类和目录》内），不能按职业病申请待遇。

## 关于心理危机这一节的处理方式

第 3 节是最敏感的一节，本书的处理方式是：

1. **不写方法、不写案例细节。** 关于「怎么做」的信息，对处在危机中的人是伤害而不是帮助。
2. **不把心理危机描述成「看不出来、无法预防」。** 绝大多数危机有可识别的前兆，而且可干预。
3. **给出准确、可核对的求助渠道**：**12356**（全国统一心理援助热线，2025 年 5 月 1 日起全国开通，匿名，每日不少于 18 小时服务）；**有立即危险时打 120 或 110**。

`skills/teacher-guide/SKILL.md` 里有一条硬规矩：**遇到危机信号时停止讲解，直接给求助信息**，不得用统计数据去回应处在危机中的人。

## 构建

```bash
node tools/build-all.mjs            # 全部格式
node tools/build-all.mjs --no-pdf   # 跳过 PDF（不需要装 reportlab）
```

PDF 需要 Python 的 reportlab：`pip install reportlab`。构建脚本会自动探测中文字体，macOS / Linux / Windows 都能跑；Linux 上如报找不到字体，`apt-get install -y fonts-noto-cjk`。

### 三条构建约定

**一、解析逻辑只有一份，且有一致性检查兜底。**
`tools/lib/book.mjs` 是工具侧解析器，`index.html` 带一份等价的浏览器端实现（页面要能独立运行）。`build-all.mjs` 每次构建前会在真实正文上跑两边、**逐字段比对 84 条**，不一致直接失败。这道检查拦的是最阴的一类 bug：网页上看到的和电子书里印出来的不是同一批内容。

**二、数据中转保证一致。**
`build-data.mjs` 先把正文规范化成 `dist/book.json`，EPUB 和 PDF 都吃这一份，所以电子书和纸质版必然一致。

**三、构建脚本的替换锚点是硬校验的。**
改 `index.html` 结构导致锚点失效时，脚本直接报错，不会静默产出一个坏文件。

### 推送

普通 `git push` 需要连 github.com:443。如果所在网络只放行 `api.github.com`（`git push` 会报 `CONNECT tunnel failed, response 502`，直连也连不上），用仓库自带的脚本改走 REST API：

```bash
python3 tools/push-via-api.py --dry-run   # 先检查
python3 tools/push-via-api.py             # 推送
```

它会把当前 HEAD 的 blob 逐个上传、建 tree 和 commit、更新分支，并**校验远端算出的 blob / tree / commit SHA 与本地完全一致**，不一致就中止。

## 已知限制

- PDF 里有个别行会把句号或顿号挤到下一行行首（70 页里 2 处）。原因是 reportlab 的中文断行对「恰好排满一行」的取舍。
- 「教师是否会被 AI 取代」这类预测无法用调查回答，本书只给出可测量的部分（使用率、使用深度、政策门槛），不给结论。
- 各省的岗位结构比例、职称细则、申诉程序差异很大。本书引用的省级文件是**样本**，用之前要去本省人社厅或教育厅官网核对。
- 离线单文件版是快照，不会随正文自动更新。

## 下一批可以加什么

现在 12 节 84 条，覆盖了身心健康、工作量、学生与家长、升学评价、高校考核、职称、平台、待遇维权、AI 九块。还值得做的：

1. **班主任专章**——这是唯一一个「所有压力叠加在一个人身上」的岗位，目前只在第 4、6 节零散提到。
2. **新手教师前三年**——入职适应、师徒制、第一次带班、第一次被投诉。目前书里默认读者已经在这个职业里待了一段时间。
3. **县中与乡村教师**——编制、轮岗、生活成本、婚恋与家庭，和城市学校是完全不同的处境。
4. **各省差异表**——岗位结构比例、职称细则、申诉程序逐省列成表，替换现在「样本省份」的写法。工作量很大，但这是读者最常问的。
